2) How Visual Manager works

  1. Open Visual Manager from title bar.
  2. In Visual Catalog, add visuals and reorder/toggle visibility.
  3. Use Auto add with Candidate Columns for auto-selection + auto-mapping.
  4. Open per-visual Visual Settings to fine-tune mapping/options/filter/advanced.
  5. Click Apply (menu remains open); close by Close button or backdrop click.

6) Auto Visual + Candidate Columns mapping

Auto visual now performs two steps:

  1. Select visual type from candidate profile (numeric/date/dimension mix).
  2. Auto-map matching mapping/measures slots (x/y/series/value/etc.) where empty.

If mapping is still incomplete, open Visual Settings → Mapping and adjust manually.

7) Targets and reference lines

  • Target mode supports manual and columns (min/max columns averaged over rows).
  • Target lines/bands render on cartesian visuals where wired.
  • Line visual adds legend helper traces for target/reference lines.

8) Test data and test approach for all visual types

Use VM_V3_TEST_DATA.json and paste into Data & Defaults tab.

  1. Add one visual per available type from Visual Catalog.
  2. Use Auto + Candidate Columns first, then verify Mapping tab values.
  3. For each visual: test Format, Filter, Advanced and Apply behavior.
  4. Validate modebar actions and legend/targets for cartesian types.

9) Known limitations / unwired areas to watch

  • Not all advanced options apply to every visual type; some are type-specific by design.
  • Auto-map is best-effort and may need manual correction for specialized visuals.
  • Target legend helper traces are explicitly added for line visual path; other visuals rely on layout shapes.
